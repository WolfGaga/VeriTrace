AN EVOLVING MENTAL MODEL

Three loops keep inquiry connected to evidence.

01

Interpretive update

Read each finding against the current task understanding. Track what is established, contradictory or still unresolved.

02

Deviation feedback

Compare the obtained evidence with task expectations, then choose a more targeted search strategy.

03

Schema revision

Revise the cognitive graph when discoveries call for a different conceptual structure.
